## 1. Problem

A Go consulting firm wants a first open-source package to show its craft: a **trimmed mean**, symmetric or
asymmetric, that any Go program can fetch with `go get` and trust. "Trust" means two things here: it agrees
with the reference implementation analysts already use (R's `mean(x, trim)`), and it refuses inputs where a
trimmed mean is undefined or misleading instead of returning a quiet wrong number.

## 2. Users

| User | Needs |
|---|---|
| **Go developer** (the firm's prospective client) | `go get` one module with no dependencies; one obvious function; clear errors; documentation with runnable examples |
| **Analyst moving from R** | Same answer as `mean(x, trim)` for symmetric trimming, and a written list of where the package deliberately differs |
| **Grader** | Two repositories, a README in each, instructions to get, use, build, run and test, and the Go-versus-R comparison |

## 3. Definitions

- **Proportions.** `low` and `high` are the proportions of the **sorted** observations removed from the lower
  and upper ends.
- **Counts.** For `n` observations: `dropLow = floor(n × low)`, `dropHigh = floor(n × high)`, computed in
  float64 exactly as R computes `floor(n * trim)`, so that `n = 100, trim = 0.29` drops 28 (spike P1).
- **Trimmed mean.** The arithmetic mean of `sorted[dropLow : n − dropHigh]`, computed **as R computes it**
  (spike addendum B): for **integer** types, one sum (exact below 2^53) divided by the count; for **float**
  types, R's two-pass mean (the first estimate plus the mean of the deviations from it), and, if the first
  sum overflows, R's fallback of adding each value divided by the count. When nothing is trimmed, the values
  are averaged in their given order, without sorting, as R does.
- **Symmetric** when only one proportion is given: `low = high = trim`. With `low = high`, this is R's
  `mean(x, trim)`. **Asymmetric** when two are given; R has no built-in, so this is **our** definition,
  evaluated in R the same way for cross-checking (spike §3).

## 7. Comparison rule with R (fixed before measuring; constitution 1.1)

Settled by spike 001 addendum B (R 4.4.2, aarch64-apple-darwin, 8-byte long double):

- **Exact agreement** (identical float64) for: every **integer** row; every **untrimmed** row; every
  **asymmetric** row (R evaluates our definition with a full sort, as Go does).
- **Trimmed symmetric float rows:** exact agreement with **R's mean of the fully sorted kept values**, **and**
  `|Go − R built-in| ≤ 10⁻¹⁴ × mean(|kept values|)`. Reason: R's built-in adds the kept values in the order its
  partial sort leaves them; the measured worst gap is 4.7 × 10⁻¹⁶ on that scale, so the limit is 20 times it.
- Go must read the samples as the same doubles R read: Go's parse of each sample equals R's saved
  `*-as-read-by-r.txt` value (a test).
- The comparison reports, per row: Go value, R value, difference in units in the last place (ULPs), and
  PASS/FAIL. A single FAIL makes the run exit 1.

## 8. Limits and consequences

### 8.1 Boundaries

Messages in this table are the **program's**; the package returns the matching error (FR-4).

| Item | Supported | Rejected, with message and exit code |
|---|---|---|
| Element types | all Go integer and float types | — (compile-time) |
| Number of values | 1 to memory limits (benchmarked to 10^6) | 0: `ErrEmpty` → program: `no numbers in FILE` · exit 2 |
| Proportions | each in [0, 0.5); one or two of them | NaN, < 0, ≥ 0.5: `ErrProportion` → `trim proportion 0.6 is outside [0, 0.5)` · exit 2; three or more: `ErrProportionCount` · exit 2 |
| Values | any non-NaN number; ±Inf values accepted when the **result** is finite (trimmed away) | NaN value: `ErrNaN` · exit 2; NaN or infinite **result**: `ErrNotFinite` · exit 1 |
| Integer magnitude | exact when every value and the sum are below 2^53 in magnitude | beyond: still computed, documented loss of precision (README limit) |
| Input file | one number per line, optional `value` header | missing file, unreadable line (`line 7: "12abc" is not a number`) · exit 2 |
| Flags | `-data`, `-trim`, `-cpuprofile`, `-memprofile` | unknown flag, `-trim` without `-data`, malformed `-trim` · usage text · exit 2 |

### 8.2 Deliberate differences from R (README table)

| Case | R | This package | Why |
|---|---|---|---|
| negative trim | ignored, untrimmed mean | `ErrProportion` | a negative proportion is a caller mistake, not a request |
| trim ≥ 0.5 | returns the median | `ErrProportion` | a mean function that silently returns a median surprises callers |
| NA / NaN in data | `NA` | `ErrNaN` | an error says where; `NA` propagates silently |
| empty data | `NaN` | `ErrEmpty` | same |

**Same as R** (not a difference, listed because it surprises): when the sum of very large values overflows, R re-adds each value divided by the count and returns a finite mean; the package does the same.
| ±Inf kept, result NaN | `NaN` | `ErrNotFinite` | no silent NaN |

(Every R behaviour in this table is confirmed by `testdata/r-reference/semantics.tsv`, spike addendum B.)

### 8.3 Failure behaviour

- **Bad input:** rejected before any computation, with the line number or value; nothing written.
- **Partial failure (comparison mode):** every row is still compared and reported; the exit code says whether
  all agreed. `results/comparison.tsv` is written to a temporary file and renamed, so an interrupted or failed
  write never leaves a half file.
- **Interruption (Ctrl-C), full disk:** the program has nothing to clean up beyond the temporary file; a write
  error is reported with the path and exit 1.
- **Timeout:** not applicable (no network, bounded work).

### 8.4 Unintended consequences

| For | Risk | Guard |
|---|---|---|
| Data | the caller's slice reordered by sorting | FR-3, tested by comparing the input before and after |
| Data | personal data in committed samples | samples are synthetic, from a seeded script (constitution 8.3); data gate |
| Users | a misleading number (NaN, a median presented as a mean, silent precision loss) | FR-4, §8.2, the integer limit in the README |
| Users | believing asymmetric results are "R's" | README says asymmetric is our definition, cross-checked in R |
| External systems | a mistaken release cached forever by the Go module proxy | a tag is pushed only after the package's acceptance passes; never moved; a fix gets a new version (constitution 9.2) |

## 11. Open decisions (recommendation first)

| Q | Decision | Recommendation and reason |
|---|---|---|
| Q1 | API shape | **One variadic `Mean(values, proportions...)`**: it reads exactly like the assignment ("if only one argument is provided … symmetric"). Cost: three or more proportions are caught at run time (`ErrProportionCount`), not compile time (R1 4.4). Alternative: separate `Symmetric` and `Asymmetric` functions — clearer types, but two names for one idea. R1 agrees. |
| Q2 | "Integers and/or floats" | **Generics (`[T Number]`)**: one function for every numeric slice, checked at compile time. A Go slice holds one type, so a mixed list is passed as `[]float64`. Alternative: `[]any`, which loses type safety. |
| Q3 | Infinite values | **Allow ±Inf; reject a NaN or infinite result (`ErrNotFinite`)**: trimming is meant to remove extreme values, and the error catches the only harmful case. Alternative: reject any non-finite value. |
| Q4 | trim ≥ 0.5 | **Reject (`ErrProportion`)** with a message that names R's median behaviour. Alternative: return the median as R does. |
| Q5 | Asymmetric flag syntax | **`-trim "low,high"`**, one flag mirroring the function. Alternative: `-low` and `-high`. |
| Q6 | First release version | **`v0.1.0`** as soon as the package passes its tests, so the program can be built against it; **`v1.0.0`** after R2's fixes, and the program moves to it in the final acceptance step (recommendation changed after R1). No tag is ever moved. Alternative: `v1.0.0` straight away, with `v1.0.1` for any R2 fix. |
| Q7 | Float comparison rule | **As §7**, settled by spike evidence; reproducing R's partial sort is **not** recommended: it would tie the package's arithmetic to R's internals for a gap of about two machine epsilons. |

A Go program that uses the trimmed-mean package

## Getting and using the package

These steps use the package in **your own** Go program; nothing from this repository is needed.

1. Install Go 1.24 or later (<https://go.dev/dl/>), and check it with `go version`.
2. Make a folder for your program and start a module in it:

   ```bash
   mkdir mystats && cd mystats
   go mod init example.com/mystats
   ```

3. Get the package (this writes it into `go.mod` and its checksum into `go.sum`):

   ```bash
   go get github.com/mioluigi/trimmedmean@v1.0.0
   ```

4. Write `main.go`:

   ```go
   package main

   import (
   	"errors"
   	"fmt"
   	"log"

   	"github.com/mioluigi/trimmedmean"
   )

   func main() {
   	values := []float64{2.1, 2.4, 2.2, 2.3, 9.9, 2.5, 2.2, 0.1, 2.4, 2.3}

   	symmetric, err := trimmedmean.Mean(values, 0.1) // 10% from each end
   	if err != nil {
   		log.Fatal(err)
   	}
   	asymmetric, err := trimmedmean.Mean(values, 0.1, 0.2) // 10% from the bottom, 20% from the top
   	if err != nil {
   		log.Fatal(err)
   	}
   	fmt.Println(symmetric, asymmetric)

   	if _, err := trimmedmean.Mean(values, 0.5); errors.Is(err, trimmedmean.ErrProportion) {
   		fmt.Println("rejected:", err)
   	}
   }
   ```

5. Run it with `go run .`. It prints the two trimmed means, then the reason a proportion of 0.5 was
   rejected.

The package's own [README](https://github.com/mioluigi/trimmedmean#readme) documents every call, error and
limit. In short: no proportion gives the ordinary mean; **one** proportion trims **symmetrically**, like R's
`mean(x, trim)`; **two** trim the bottom and the top separately; each proportion must be in `[0, 0.5)`.
Integers (`[]int`, `[]int64`, …) and floats (`[]float64`, `[]float32`, …) are both accepted.

**With no arguments** the program computes all 84 cases R saved (8 symmetric proportions and 6 asymmetric
pairs for each of the 6 samples), judges each by the rule below, prints the `trim = 0.05` comparison and a
one-line verdict, and writes the full table to `results/comparison.tsv`. **With `-data FILE`** it computes
one trimmed mean; `-trim P` trims `P` from each end (default 0.05), `-trim LOW,HIGH` trims the two ends
separately. The input file has one number per line, optionally under a first line `value`; blank lines are
ignored; a file of whole numbers is read as integers.

| Option | Meaning |
|---|---|
| `-data FILE` | compute one trimmed mean of FILE |
| `-trim P` or `-trim LOW,HIGH` | proportions trimmed (with `-data`) |
| `-data-dir`, `-reference`, `-out` | comparison mode: samples, R's results, output table |
| `-cpuprofile FILE`, `-memprofile FILE` | write profiles |

Logs (what was read and computed) go to standard error; results to standard output.

| Exit code | Meaning | Examples |
|---|---|---|
| 0 | success; in comparison mode, every row agrees with R | |
| 1 | a comparison with R failed, or the mean is not finite | `-data f.csv -trim 0` on a file holding both `-Inf` and `Inf` |
| 2 | a usage or input error, with a message saying what to fix | `-trim 0.6` → `trim proportion must be in [0, 0.5): got 0.6`; a line `12abc` → `line 3: "12abc" is not a number`; an empty file → `no numbers in FILE`; `-trim` without `-data` |

## How the comparison with R works

R's results come from [`r/capture-reference.R`](r/capture-reference.R), run once on the Mac: it generated
the samples (seed 9431; floats written with 4 decimals), read them back, and saved `mean(x, trim)` for each.
What R does was learned by running it ([spike 001](docs/spikes/001-environment-and-r-reference.md)):

- R removes `floor(n × trim)` values from each end, in float64: `100 × 0.29` removes 28, not 29. The
  package does the same.
- R averages **integers** with one exact sum divided by the count, and **doubles** with a two-pass method;
  the package does the same, so for the same numbers an integer and a float sample can differ in the last
  digit, in R and in Go alike.
- R sorts only **partly** before averaging, so it adds the kept values in a different order from a full sort.
  On a computer, a sum depends on the order, so R's own result changes in the last digits. Measured on these
  samples, the gap is at most about two machine epsilons, relative to the size of the values.

The rule ([spec §7](specs/001-trimmed-mean/spec.md)) follows from this. Results must be **identical** for
integer samples, untrimmed means and the asymmetric definition. For trimmed float samples, Go must be
identical to R's mean of the fully sorted kept values, **and** within 10⁻¹⁴ × the mean absolute kept value of
R's `mean(x, trim)` (about 20 times the largest gap measured). Asymmetric trimming has no R function, so R
evaluated the package's definition for the 36 asymmetric cases.

## Limits

| Limit | Behaviour |
|---|---|
| Proportions | each in `[0, 0.5)`, one or two of them; anything else is an error (exit 2). R instead returns the median for 0.5 or more and ignores a negative trim |
| Values | NaN is rejected (exit 2); `±Inf` are accepted if they are trimmed away; a NaN or infinite result is an error (exit 1) |
| Integers | exact up to 2^53 in magnitude (values and their sum); larger integers lose precision as float64 |
| Floats against R | identical to R's full-sort mean; within about two machine epsilons of R's `mean(x, trim)` (see above) |
| Size | memory for one float64 copy (8 bytes per value) plus the file being read; time `O(n log n)` |
| Input files | one number per line, optional `value` header; a line that is not a number stops the run with its line number |
| R results | saved from R 4.4.2 on an Apple-silicon Mac; regenerating them on another platform could change the last digits of the float rows |

// Command go-trimmed-mean-demo shows the trimmedmean package in use.
//
// With no arguments it checks the package against R's saved results on the committed samples, prints
// the comparison at trim = 0.05 (R's mean(x, trim = 0.05)), and writes every comparison to
// results/comparison.tsv. With -data and -trim it computes one trimmed mean for a file of numbers.
//
// Exit codes: 0 success; 1 a comparison with R failed, or a run-time failure; 2 a usage or input error.
package main

import (
	"errors"
	"flag"
	"fmt"
	"io"
	"log/slog"
	"math"
	"os"
	"strconv"
	"strings"

	"github.com/mioluigi/go-trimmed-mean-demo/internal/sample"
	"github.com/mioluigi/trimmedmean"
)

const (
	exitOK      = 0
	exitFailure = 1
	exitUsage   = 2
)

// Errors for command-line mistakes; they lead to exit code 2.
var (
	errTrimWithoutData = errors.New("-trim needs -data FILE")
	errBadTrim         = errors.New("-trim must be one proportion (0.05) or two separated by a comma (0.05,0.10)")
)

// options are the command-line settings.
type options struct {
	data, trim              string // one-file mode
	dataDir, reference, out string // comparison mode
	cpuProfile, memProfile  string
}

func main() {
	os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))
}

// run is the whole program; it returns the exit code so that tests can call it.
func run(args []string, stdout, stderr io.Writer) int {
	opts, err := parseFlags(args, stderr)
	if err != nil {
		return exitUsage
	}
	logger := slog.New(slog.NewTextHandler(stderr, nil))
	stopProfiles, err := startProfiles(opts)
	if err != nil {
		fmt.Fprintln(stderr, "error:", err)
		return exitFailure
	}
	defer stopProfiles(logger)

	switch {
	case opts.data != "":
		err = runOne(opts, stdout, logger)
	case opts.trim != "":
		err = errTrimWithoutData
	default:
		err = runComparison(opts, stdout, logger)
	}
	if err != nil {
		fmt.Fprintln(stderr, "error:", err)
	}
	return exitCode(err)
}

// exitCode maps an error to the program's exit code: input and usage mistakes are 2, the rest 1.
func exitCode(err error) int {
	if err == nil {
		return exitOK
	}
	usageErrors := []error{
		errTrimWithoutData, errBadTrim, os.ErrNotExist, sample.ErrNoNumbers, sample.ErrNotNumber,
		trimmedmean.ErrEmpty, trimmedmean.ErrNaN, trimmedmean.ErrProportion, trimmedmean.ErrProportionCount,
	}
	for _, usageError := range usageErrors {
		if errors.Is(err, usageError) {
			return exitUsage
		}
	}
	return exitFailure
}

// runOne computes one trimmed mean for the file named by -data and reports it in plain words.
func runOne(opts options, stdout io.Writer, logger *slog.Logger) error {
	trim := opts.trim
	if trim == "" {
		trim = "0.05"
	}
	proportions, err := parseProportions(trim)
	if err != nil {
		return err
	}
	values, err := sample.Read(opts.data)
	if err != nil {
		return err
	}
	mean, err := meanOf(values, proportions)
	if err != nil {
		return fmt.Errorf("%s: %w", opts.data, err)
	}
	low, high := proportions[0], proportions[len(proportions)-1]
	logger.Info("computed", "file", opts.data, "n", values.Len(), "low", low, "high", high)
	fmt.Fprintf(stdout, "%s: %d %s\n", opts.data, values.Len(), kindName(values))
	fmt.Fprintf(stdout, "trimmed %v from the bottom and %v from the top (%d and %d values dropped)\n",
		low, high, dropped(values.Len(), low), dropped(values.Len(), high))
	fmt.Fprintf(stdout, "trimmed mean: %v\n", mean)
	return nil
}

// parseProportions reads "p" or "low,high".
func parseProportions(text string) ([]float64, error) {
	parts := strings.Split(text, ",")
	proportions := make([]float64, len(parts))
	for i, part := range parts {
		value, err := strconv.ParseFloat(strings.TrimSpace(part), 64)
		if err != nil {
			return nil, fmt.Errorf("%w: got %q", errBadTrim, text)
		}
		proportions[i] = value
	}
	return proportions, nil
}

// meanOf calls the package with the sample's own element type.
func meanOf(values sample.Sample, proportions []float64) (float64, error) {
	if values.IsInteger() {
		return trimmedmean.Mean(values.Integers, proportions...)
	}
	return trimmedmean.Mean(values.Floats, proportions...)
}

// dropped is the number of values removed from one end, for the report only: floor(n × p), the rule
// the package applies (spec §3).
func dropped(n int, proportion float64) int {
	return int(math.Floor(float64(n) * proportion))
}

func kindName(values sample.Sample) string {
	if values.IsInteger() {
		return "integers"
	}
	return "floats"
}

// headlineTrim is the proportion the assignment compares with R: mean(x, trim = 0.05).
const headlineTrim = 0.05

// comparison is one reference row with Go's value and the verdict.
type comparison struct {
	reference compare.Reference
	got       float64
	result    compare.Result
}

// runComparison checks every row of R's reference against the package, writes the full table, and prints
// the trim = 0.05 rows and a one-line verdict. It returns an error if any row disagrees.
func runComparison(opts options, stdout io.Writer, logger *slog.Logger) error {
	references, err := compare.ReadReferences(opts.reference)
	if err != nil {
		return err
	}
	comparisons, err := compareAll(opts.dataDir, references, logger)
	if err != nil {
		return err
	}
	if err := writeTable(opts.out, comparisons); err != nil {
		return err
	}
	printHeadline(stdout, comparisons)

	failed := countFailed(comparisons)
	fmt.Fprintf(stdout, "\n%d of %d comparisons with R agree (rule: spec §7). Full table: %s\n",
		len(comparisons)-failed, len(comparisons), opts.out)
	if failed > 0 {
		return fmt.Errorf("%d comparisons with R failed; see %s", failed, opts.out)
	}
	return nil
}

// compareAll computes Go's trimmed mean for every reference row, reading each sample once.
func compareAll(dataDir string, references []compare.Reference, logger *slog.Logger) ([]comparison, error) {
	samples := map[string]sample.Sample{}
	comparisons := make([]comparison, 0, len(references))
	for _, reference := range references {
		values, ok := samples[reference.Sample]
		if !ok {
			var err error
			values, err = readMatching(dataDir, reference)
			if err != nil {
				return nil, err
			}
			samples[reference.Sample] = values
			logger.Info("read sample", "sample", reference.Sample, "n", values.Len(), "kind", kindName(values))
		}
		got, err := meanOf(values, []float64{reference.Low, reference.High})
		if err != nil {
			return nil, fmt.Errorf("%s %v/%v: %w", reference.Sample, reference.Low, reference.High, err)
		}
		result := compare.Check(reference, got, keptValues(values, reference))
		comparisons = append(comparisons, comparison{reference, got, result})
	}
	return comparisons, nil
}

// readMatching reads the sample a reference row names and checks it is the size and kind R saw.
func readMatching(dataDir string, reference compare.Reference) (sample.Sample, error) {
	values, err := sample.Read(filepath.Join(dataDir, reference.Sample+".csv"))
	if err != nil {
		return sample.Sample{}, err
	}
	sameKind := values.IsInteger() == (reference.Kind == "integer")
	if values.Len() != reference.N || !sameKind {
		return sample.Sample{}, fmt.Errorf("sample %s: %d %s, but R's reference has %d %s values",
			reference.Sample, values.Len(), kindName(values), reference.N, reference.Kind)
	}
	return values, nil
}

// keptValues returns the values R kept for a row (in sorted order), for the tolerance's scale.
func keptValues(values sample.Sample, reference compare.Reference) []float64 {
	sorted := make([]float64, 0, values.Len())
	for _, value := range values.Integers {
		sorted = append(sorted, float64(value))
	}
	sorted = append(sorted, values.Floats...)
	slices.Sort(sorted)
	return sorted[reference.DropLow : len(sorted)-reference.DropHigh]
}

// printHeadline prints the rows for R's mean(x, trim = 0.05), the comparison the assignment asks for.
func printHeadline(stdout io.Writer, comparisons []comparison) {
	fmt.Fprintln(stdout, "Go trimmedmean.Mean(x, 0.05) against R mean(x, trim = 0.05), committed samples:")
	table := tabwriter.NewWriter(stdout, 0, 0, 2, ' ', 0)
	fmt.Fprintln(table, "sample\tn\tkind\tGo\tR\tdifference (ULPs)\tverdict")
	for _, c := range comparisons {
		symmetric := c.reference.Method == compare.BuiltIn && c.reference.Low == headlineTrim
		if symmetric {
			fmt.Fprintf(table, "%s\t%d\t%s\t%.17g\t%.17g\t%d\t%s\n", c.reference.Sample, c.reference.N,
				c.reference.Kind, c.got, c.reference.Value, c.result.ULPs, verdict(c.result))
		}
	}
	table.Flush()
}

// writeTable writes every comparison as a tab-separated table. It writes a temporary file in the same
// folder and renames it, so a failed or interrupted run never leaves a half-written table.
func writeTable(path string, comparisons []comparison) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o755); err != nil {
		return err
	}
	temporary, err := os.CreateTemp(filepath.Dir(path), ".comparison-*.tsv")
	if err != nil {
		return err
	}
	defer os.Remove(temporary.Name()) // no effect after a successful rename

	fmt.Fprintln(temporary, "sample\tkind\tn\tlow\thigh\tmethod\tgo\tr\tr_full_sort\tulps\tlimit\trule\tverdict")
	for _, c := range comparisons {
		r := c.reference
		fmt.Fprintf(temporary, "%s\t%s\t%d\t%v\t%v\t%s\t%.17g\t%.17g\t%.17g\t%d\t%.3g\t%s\t%s\n",
			r.Sample, r.Kind, r.N, r.Low, r.High, r.Method, c.got, r.Value, r.FullSortValue,
			c.result.ULPs, c.result.Limit, c.result.Rule, verdict(c.result))
	}
	if err := temporary.Close(); err != nil {
		return fmt.Errorf("writing %s: %w", path, err)
	}
	return os.Rename(temporary.Name(), path)
}

func countFailed(comparisons []comparison) int {
	failed := 0
	for _, c := range comparisons {
		if !c.result.Pass {
			failed++
		}
	}
	return failed
}

func verdict(result compare.Result) string {
	if result.Pass {
		return "PASS"
	}
	return "FAIL"
}

// Package compare holds the rule by which a Go trimmed mean is judged to agree with R's (spec §7), and
// reads R's saved reference results.
package compare

import (
	"encoding/csv"
	"fmt"
	"math"
	"os"
	"strconv"
)

// Tolerance bounds |Go − R built-in| for trimmed symmetric float rows, as a multiple of the mean absolute
// kept value. R adds the kept values in the order its partial sort leaves them; the measured worst gap is
// 4.7e-16 on that scale (spike 001 addendum B), so this limit is about 20 times it.
const Tolerance = 1e-14

// Methods named in the reference file.
const (
	BuiltIn = "mean(x, trim)" // R's own trimmed mean (symmetric)
	Defined = "defined"       // our asymmetric definition, evaluated in R with a full sort
)

// Rules a comparison can be judged by.
const (
	RuleExact     = "exact"
	RuleTolerance = "exact full sort + tolerance"
)

// Reference is one row of R's results (testdata/r-reference/trimmed-means.tsv).
type Reference struct {
	Sample, Kind, Method string
	N                    int
	Low, High            float64
	Value                float64 // R's result
	FullSortValue        float64 // R's mean of the fully sorted kept values
	DropLow, DropHigh    int
}

// Result is the verdict on one Go value.
type Result struct {
	Rule  string
	ULPs  uint64  // distance from R's value in units in the last place
	Limit float64 // absolute limit used by the tolerance rule; 0 for the exact rule
	Pass  bool
}

// Check judges got against reference by spec §7: exact for integer rows, untrimmed rows and our
// asymmetric definition; for trimmed symmetric float rows, exact against R's full-sort mean and within
// Tolerance × mean(|kept|) of R's built-in. kept is the values the trimmed mean averaged.
func Check(reference Reference, got float64, kept []float64) Result {
	ulps := ULPDistance(got, reference.Value)
	if needsExact(reference) {
		return Result{Rule: RuleExact, ULPs: ulps, Pass: ulps == 0}
	}
	limit := Tolerance * meanAbsolute(kept)
	pass := got == reference.FullSortValue && math.Abs(got-reference.Value) <= limit
	return Result{Rule: RuleTolerance, ULPs: ulps, Limit: limit, Pass: pass}
}

// needsExact reports whether a row must agree exactly: integers sum exactly in any order, untrimmed
// values are added in the same order by R and Go, and our definition is sorted fully on both sides.
func needsExact(reference Reference) bool {
	untrimmed := reference.Low == 0 && reference.High == 0
	return reference.Kind == "integer" || untrimmed || reference.Method == Defined
}

// ULPDistance returns how many representable float64 values lie between a and b (0 when equal; +0 and
// −0 count as equal).
func ULPDistance(a, b float64) uint64 {
	ordered := func(x float64) int64 {
		bits := int64(math.Float64bits(x))
		if bits < 0 {
			return math.MinInt64 - bits // map negative floats below the positive ones, in order
		}
		return bits
	}
	difference := ordered(a) - ordered(b)
	if difference < 0 {
		return uint64(-difference)
	}
	return uint64(difference)
}

func meanAbsolute(values []float64) float64 {
	total := 0.0
	for _, value := range values {
		total += math.Abs(value)
	}
	return total / float64(len(values))
}

// ReadReferences reads R's saved results.
func ReadReferences(path string) ([]Reference, error) {
	file, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer file.Close()
	reader := csv.NewReader(file)
	reader.Comma = '\t'
	records, err := reader.ReadAll()
	if err != nil {
		return nil, fmt.Errorf("reading %s: %w", path, err)
	}
	if len(records) < 2 {
		return nil, fmt.Errorf("%s has no reference rows", path)
	}
	references := make([]Reference, 0, len(records)-1)
	for line, record := range records[1:] {
		reference, err := parseReference(record)
		if err != nil {
			return nil, fmt.Errorf("%s line %d: %w", path, line+2, err)
		}
		references = append(references, reference)
	}
	return references, nil
}

// parseReference turns one record (sample, kind, n, low, high, method, value, dropped_low, dropped_high,
// identical_to_full_sort, identical_as_double, full_sort_value) into a Reference.
func parseReference(record []string) (Reference, error) {
	if len(record) != 12 {
		return Reference{}, fmt.Errorf("%d fields, want 12", len(record))
	}
	numbers := make([]float64, 0, 7)
	for _, index := range []int{2, 3, 4, 6, 7, 8, 11} {
		value, err := strconv.ParseFloat(record[index], 64)
		if err != nil {
			return Reference{}, fmt.Errorf("field %d: %w", index+1, err)
		}
		numbers = append(numbers, value)
	}
	return Reference{
		Sample: record[0], Kind: record[1], Method: record[5],
		N: int(numbers[0]), Low: numbers[1], High: numbers[2], Value: numbers[3],
		DropLow: int(numbers[4]), DropHigh: int(numbers[5]), FullSortValue: numbers[6],
	}, nil
}

// Package sample reads a column of numbers from a text file, as integers when every value is a whole
// number and as floats otherwise.
package sample

import (
	"bufio"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"strconv"
	"strings"
)

// Errors returned by Read; the message also names the file and, for ErrNotNumber, the line.
var (
	// ErrNoNumbers means the file holds no values (it may hold only the header).
	ErrNoNumbers = errors.New("no numbers")
	// ErrNotNumber means a line is neither a number nor the header.
	ErrNotNumber = errors.New("not a number")
)

// header is the optional first line of a sample file.
const header = "value"

// Sample is one column of numbers. Exactly one of Integers and Floats holds the values.
type Sample struct {
	Name     string // the file name without directory and extension, e.g. "floats-100"
	Integers []int
	Floats   []float64
}

// IsInteger reports whether the sample was read as integers.
func (s Sample) IsInteger() bool { return s.Integers != nil }

// Len returns the number of values.
func (s Sample) Len() int { return len(s.Integers) + len(s.Floats) }

// Read reads one number per line from path. Blank lines and a first line "value" are skipped. If every
// value is a whole number written without a decimal point the sample is integer, otherwise float.
func Read(path string) (Sample, error) {
	texts, err := readValueLines(path)
	if err != nil {
		return Sample{}, err
	}
	name := strings.TrimSuffix(filepath.Base(path), filepath.Ext(path))
	if integers, ok := parseIntegers(texts); ok {
		return Sample{Name: name, Integers: integers}, nil
	}
	floats, err := parseFloats(path, texts)
	if err != nil {
		return Sample{}, err
	}
	return Sample{Name: name, Floats: floats}, nil
}

// valueLine is a non-blank line and its 1-based line number, kept for error messages.
type valueLine struct {
	number int
	text   string
}

// readValueLines returns the non-blank lines after the optional header.
func readValueLines(path string) ([]valueLine, error) {
	file, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer file.Close()

	var lines []valueLine
	scanner := bufio.NewScanner(file)
	for number := 1; scanner.Scan(); number++ {
		text := strings.TrimSpace(scanner.Text())
		isHeader := number == 1 && text == header
		if text != "" && !isHeader {
			lines = append(lines, valueLine{number, text})
		}
	}
	if err := scanner.Err(); err != nil {
		return nil, fmt.Errorf("reading %s: %w", path, err)
	}
	if len(lines) == 0 {
		return nil, fmt.Errorf("%w in %s", ErrNoNumbers, path)
	}
	return lines, nil
}

// parseIntegers parses every line as an integer, or reports false if any line is not one.
func parseIntegers(lines []valueLine) ([]int, bool) {
	integers := make([]int, len(lines))
	for i, line := range lines {
		value, err := strconv.Atoi(line.text)
		if err != nil {
			return nil, false
		}
		integers[i] = value
	}
	return integers, true
}

// parseFloats parses every line as a float64, naming the first line that is not a number.
func parseFloats(path string, lines []valueLine) ([]float64, error) {
	floats := make([]float64, len(lines))
	for i, line := range lines {
		value, err := strconv.ParseFloat(line.text, 64)
		if err != nil {
			return nil, fmt.Errorf("%s line %d: %q is %w", path, line.number, line.text, ErrNotNumber)
		}
		floats[i] = value
	}
	return floats, nil
}

# trimmedmean

A Go package that computes the **trimmed mean** of a slice of integers or floating-point numbers, with
**symmetric** or **asymmetric** trimming. With one proportion it gives the same result as R's
`mean(x, trim)`.

- One function, `trimmedmean.Mean`, for every Go integer and float type (generics).
- No dependencies outside the Go standard library.
- Never changes your slice, never panics on bad input, and returns errors you can test with `errors.Is`.
- Checked against R 4.4.2 on 84 reference results ([Tests](#tests)).

A trimmed mean sorts the observations, removes a proportion of them from the lower end and a proportion
from the upper end, and averages the rest. It resists outliers better than the ordinary mean, and uses
more of the data than the median.

A complete example program, which also compares this package with R, is in
[github.com/mioluigi/go-trimmed-mean-demo](https://github.com/mioluigi/go-trimmed-mean-demo).

## Install

The package needs Go 1.24 or later. In your own module:

```bash
go get github.com/mioluigi/trimmedmean@v1.0.0
```

That adds `github.com/mioluigi/trimmedmean v1.0.0` to your `go.mod` (and its checksum to `go.sum`).
Without a module yet, start one first with `go mod init example.com/yourprogram`.

## Use

```go
package main

import (
	"errors"
	"fmt"
	"log"

	"github.com/mioluigi/trimmedmean"
)

func main() {
	// One proportion: symmetric. 10% of 10 values is one value from each end,
	// so the lowest value (1) and the outlier (1000) are removed.
	scores := []int{1, 52, 48, 50, 47, 53, 49, 51, 46, 1000}
	mean, err := trimmedmean.Mean(scores, 0.1)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(mean) // 49.5

	// Two proportions: asymmetric (low, high). Nothing from the bottom, 20% from the top.
	latencies := []float64{12.5, 11.0, 13.5, 12.0, 250.0, 11.5, 13.0, 12.5, 400.0, 12.0}
	mean, err = trimmedmean.Mean(latencies, 0, 0.2)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%.4f\n", mean) // 12.2500

	// Errors name what was wrong and can be tested with errors.Is.
	_, err = trimmedmean.Mean([]float64{1, 2, 3}, 0.6)
	fmt.Println(errors.Is(err, trimmedmean.ErrProportion)) // true
	fmt.Println(err) // trimmedmean: trim proportion must be in [0, 0.5): got 0.6
}
```

These three cases are the package's `Example` functions (`example_test.go`), so `go test` compiles them
and checks every printed value.

The signature is

```go
func Mean[T Number](values []T, proportions ...float64) (float64, error)
```

| Call | Meaning |
|---|---|
| `Mean(values)` | the ordinary mean (no trimming) |
| `Mean(values, p)` | **symmetric**: removes `floor(n × p)` values from each end, like R's `mean(x, trim = p)` |
| `Mean(values, low, high)` | **asymmetric**: removes `floor(n × low)` values from the bottom and `floor(n × high)` from the top |

`Number` is every Go integer and floating-point type, and any named type based on one (for example
`type Celsius float64`). A Go slice holds one type; to average a mix of integers and floats, put them in a
`[]float64`.

## Definition

For `n` values and proportions `low` and `high`, each in `[0, 0.5)`:

1. `dropLow = floor(n × low)` and `dropHigh = floor(n × high)`, computed in float64 exactly as R computes
   `floor(n * trim)`. For example `100 × 0.29` is `28.999999999999996` in float64, so 28 values are
   removed, not 29.
2. A **copy** of the values is sorted, and the mean of `sorted[dropLow : n − dropHigh]` is returned. When
   nothing is removed, nothing is sorted.
3. The mean is computed the way R computes it: for **integer** types, one sum divided by the count (exact
   while the sum stays below 2^53); for **float** types, R's two-pass mean (the sum divided by the count,
   plus the mean of the deviations from that first estimate), with R's fallback when the sum overflows.

Because each proportion is below 0.5, at least one value is always kept.

## Errors

| Error | When | Example message |
|---|---|---|
| `ErrEmpty` | no values | `trimmedmean: no values` |
| `ErrNaN` | a value is NaN | `trimmedmean: value is NaN: at index 3` |
| `ErrProportion` | a proportion is NaN, negative, or not below 0.5 | `trimmedmean: trim proportion must be in [0, 0.5): got 0.6` |
| `ErrProportionCount` | more than two proportions | `trimmedmean: at most two trim proportions (low, high): got 3` |
| `ErrNotFinite` | the mean of the kept values is NaN or infinite (for example both `+Inf` and `−Inf` are kept) | `trimmedmean: mean is not finite: got NaN` |

Infinite **values** are accepted: `Mean([]float64{math.Inf(-1), 1, 2, 3, 4, 5, 6, 7, 8, math.Inf(1)}, 0.1)`
trims them away and returns 4.5, as R does.

## Differences from R

The symmetric trimmed mean matches R's `mean(x, trim)` (see [Tests](#tests)). Where R gives an answer
that is easy to misread, the package returns an error instead:

| Case | R's `mean(x, trim)` | `trimmedmean.Mean` | Why |
|---|---|---|---|
| negative proportion | ignores it: the untrimmed mean | `ErrProportion` | a negative proportion is a mistake, not a request |
| proportion ≥ 0.5 | returns the **median** | `ErrProportion` | a mean function that silently returns a median surprises callers; use a median function |
| `NA` or `NaN` in the data | `NA` | `ErrNaN`, with the index | an error says where; `NA` spreads silently |
| no data | `NaN` | `ErrEmpty` | same |
| two proportions | an error (`'trim' must be numeric of length one`) | asymmetric trimming | R has no asymmetric trimmed mean; this package defines it as above |

The same as R, though it may surprise: if the sum of very large values overflows, the values are added
again, each divided by the count, so the mean is still finite.

## Limits

- **Integers beyond 2^53** (about 9 × 10^15) in magnitude are converted to float64 and lose precision; so
  does a sum of integers beyond 2^53. R's integers are 32-bit, so R never meets this case.
- **Floats agree with R to within about two machine epsilons, not always to the last bit,** when values are
  trimmed: R adds the kept values in the order its partial sort leaves them, this package in sorted order.
  The integer, untrimmed and asymmetric results agree with R exactly.
- **Memory:** one copy of the input as `[]float64` (8 bytes per value). **Time:** `O(n log n)` for the sort.
- Proportions must be in `[0, 0.5)`; at most two of them.

// Package trimmedmean computes symmetric and asymmetric trimmed means of integer or floating-point
// slices.
//
// A trimmed mean sorts the observations, removes a proportion of them from the lower end and a
// proportion from the upper end, and averages the rest. It resists outliers better than the plain mean
// while using more of the data than the median.
//
// The symmetric trimmed mean agrees with R's mean(x, trim): it removes floor(n * trim) observations from
// each end, and averages the kept values the way R does (one exact sum for integers, R's two-pass method
// for floating-point values). The README of this module lists where it deliberately differs from R.
package trimmedmean

import (
	"errors"
	"fmt"
	"math"
	"slices"
)

// Number is the set of element types Mean accepts: every Go integer and floating-point type, and any
// named type based on one of them (for example, type Celsius float64).
type Number interface {
	~int | ~int8 | ~int16 | ~int32 | ~int64 |
		~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64 |
		~float32 | ~float64
}

// Errors returned by Mean. Test for them with errors.Is; the returned error also names the offending
// value.
var (
	// ErrEmpty means there were no values to average.
	ErrEmpty = errors.New("trimmedmean: no values")
	// ErrNaN means a value was NaN, so no mean is defined.
	ErrNaN = errors.New("trimmedmean: value is NaN")
	// ErrProportion means a trim proportion was NaN, negative, or not below 0.5.
	ErrProportion = errors.New("trimmedmean: trim proportion must be in [0, 0.5)")
	// ErrProportionCount means more than two trim proportions were given.
	ErrProportionCount = errors.New("trimmedmean: at most two trim proportions (low, high)")
	// ErrNotFinite means the mean of the kept values is NaN or infinite, for example when both +Inf
	// and -Inf are kept.
	ErrNotFinite = errors.New("trimmedmean: mean is not finite")
)

// Mean returns the trimmed mean of values.
//
// With no proportion it returns the ordinary mean. With one proportion p it trims symmetrically,
// removing floor(n*p) of the n sorted values from each end, as R's mean(x, trim = p) does. With two
// proportions low and high it removes floor(n*low) values from the lower end and floor(n*high) from the
// upper end. Each proportion must be in [0, 0.5), so at least one value is always kept.
//
// Mean sorts a copy, never the caller's slice, and is safe for concurrent use.
func Mean[T Number](values []T, proportions ...float64) (float64, error) {
	low, high, err := trimProportions(proportions)
	if err != nil {
		return 0, err
	}
	numbers, err := toFloat64(values)
	if err != nil {
		return 0, err
	}
	dropLow, dropHigh, err := dropCounts(len(numbers), low, high)
	if err != nil {
		return 0, err
	}

	// Like R, sort only when something is trimmed; untrimmed values are averaged in their given order.
	kept := numbers
	if dropLow+dropHigh > 0 {
		slices.Sort(numbers)
		kept = numbers[dropLow : len(numbers)-dropHigh]
	}

	var mean float64
	if isInteger[T]() {
		mean = integerMean(kept)
	} else {
		mean = floatMean(kept)
	}
	if !isFinite(mean) {
		return 0, fmt.Errorf("%w: got %v", ErrNotFinite, mean)
	}
	return mean, nil
}

// trimProportions turns the optional arguments of Mean into lower and upper proportions: none means no
// trimming, one means symmetric trimming, two mean (low, high).
func trimProportions(proportions []float64) (low, high float64, err error) {
	switch len(proportions) {
	case 0:
		return 0, 0, nil
	case 1:
		low, high = proportions[0], proportions[0]
	case 2:
		low, high = proportions[0], proportions[1]
	default:
		return 0, 0, fmt.Errorf("%w: got %d", ErrProportionCount, len(proportions))
	}
	for _, proportion := range []float64{low, high} {
		if !validProportion(proportion) {
			return 0, 0, fmt.Errorf("%w: got %v", ErrProportion, proportion)
		}
	}
	return low, high, nil
}

// validProportion reports whether p is in [0, 0.5). NaN fails both comparisons, so it is invalid.
func validProportion(p float64) bool {
	return p >= 0 && p < 0.5
}

// toFloat64 copies values into a new []float64, so that sorting never touches the caller's slice, and
// rejects an empty slice or a NaN value.
func toFloat64[T Number](values []T) ([]float64, error) {
	if len(values) == 0 {
		return nil, ErrEmpty
	}
	numbers := make([]float64, len(values))
	for i, value := range values {
		numbers[i] = float64(value)
		if math.IsNaN(numbers[i]) {
			return nil, fmt.Errorf("%w: at index %d", ErrNaN, i)
		}
	}
	return numbers, nil
}

// dropCounts returns how many of count sorted values to remove from each end. It computes floor(n*p) in
// float64 exactly as R does, so 100 * 0.29 = 28.999999999999996 drops 28. Proportions below 0.5 always
// leave a value, but for a very large count the product can round up to count/2, so the result is
// checked rather than assumed.
func dropCounts(count int, low, high float64) (dropLow, dropHigh int, err error) {
	n := float64(count)
	dropLow = int(math.Floor(n * low))
	dropHigh = int(math.Floor(n * high))
	if dropLow+dropHigh >= count {
		return 0, 0, fmt.Errorf("%w: %v and %v leave none of %d values", ErrProportion, low, high, count)
	}
	return dropLow, dropHigh, nil
}

// integerMean is R's mean for integer vectors: one sum divided by the count. The sum of integer values
// is exact while it stays below 2^53 in magnitude, so this is the correctly rounded mean.
func integerMean(values []float64) float64 {
	sum := 0.0
	for _, value := range values {
		sum += value
	}
	return sum / float64(len(values))
}

// floatMean is R's mean for double vectors. It divides the sum by the count, or, if the sum overflowed,
// adds each value already divided by the count. Then it adds the mean deviation from that first
// estimate, which removes most of the rounding error a single sum leaves.
func floatMean(values []float64) float64 {
	count := float64(len(values))
	sum := 0.0
	for _, value := range values {
		sum += value
	}
	estimate := sum / count
	if !isFinite(sum) {
		estimate = 0
		for _, value := range values {
			estimate += value / count
		}
	}
	if !isFinite(estimate) {
		return estimate
	}

	residual := 0.0
	for _, value := range values {
		residual += value - estimate
	}
	return estimate + residual/count
}

// isInteger reports whether T is an integer type: only integer division truncates 1/2 to 0.
func isInteger[T Number]() bool {
	var one T = 1
	return one/2 == 0
}

// isFinite reports whether x is neither NaN nor infinite.
func isFinite(x float64) bool {
	return !math.IsNaN(x) && !math.IsInf(x, 0)
}

// TestMeanFloorRule checks R's count rule: floor(n * p) in float64, where 100 * 0.29 is
// 28.999999999999996, so 28 values are dropped, not 29 (spike 001 P1). The upper proportion is 0 so that
// a wrong count changes the answer: dropping 28 leaves 29..100 (mean 64.5); dropping 29 would leave
// 30..100 (mean 65).
func TestMeanFloorRule(t *testing.T) {
	values := make([]int, 100)
	for i := range values {
		values[i] = i + 1
	}

	if err != nil || got != 64.5 {
		t.Fatalf("Mean(1..100, 0.29, 0) = %v, %v; want 64.5 (28 dropped)", got, err)
	}
}

package trimmedmean

import (
	"bufio"
	"encoding/csv"
	"math"
	"os"
	"path/filepath"
	"slices"
	"strconv"
	"testing"

// floatTolerance bounds |Go - R| for trimmed symmetric float rows, as a multiple of the mean absolute
// kept value. R adds the kept values in the order its partial sort leaves them; the measured worst gap
// is 4.7e-16 on that scale (spike 001 addendum B), so this limit is about 20 times it.
const floatTolerance = 1e-14

// referenceRow is one line of testdata/trimmed-means.tsv.
type referenceRow struct {
	sample, kind, method string
	low, high, value     float64
	fullSortValue        float64
	dropLow, dropHigh    int
}

// TestMeanAgreesWithR checks every R reference row under the rule of spec §7: exact for integers,
// untrimmed rows and our asymmetric definition; for trimmed symmetric floats, exact against R's own
// full-sort mean and within floatTolerance of R's built-in.
func TestMeanAgreesWithR(t *testing.T) {
	rows := readReference(t)
	if len(rows) != 84 {
		t.Fatalf("read %d reference rows, want 84", len(rows))
	}
	for _, row := range rows {
		got, kept := meanOfSample(t, row)
		exact := row.kind == "integer" || row.method == "defined" || (row.low == 0 && row.high == 0)
		if exact {
			if got != row.value {
				t.Errorf("%s %v/%v: got %.17g, R %.17g (exact)", row.sample, row.low, row.high, got, row.value)
			}
			continue
		}
		if got != row.fullSortValue {
			t.Errorf("%s %v: got %.17g, R full-sort %.17g (exact)", row.sample, row.low, got, row.fullSortValue)
		}
		if limit := floatTolerance * meanAbsolute(kept); math.Abs(got-row.value) > limit {
			t.Errorf("%s %v: |%.17g - R %.17g| > %.3g", row.sample, row.low, got, row.value, limit)
		}
	}
}

// TestGoReadsWhatRRead checks that strconv.ParseFloat reads each float sample as exactly the doubles
// R read from the same file, so both sides average the same numbers.
func TestGoReadsWhatRRead(t *testing.T) {
	for _, name := range []string{"floats-100", "floats-101", "floats-1000"} {
		ours := readColumn(t, filepath.Join("testdata", name+".csv"))
		theirs := readColumn(t, filepath.Join("testdata", name+"-as-read-by-r.txt"))
		if len(ours) != len(theirs) {
			t.Fatalf("%s: %d values, R read %d", name, len(ours), len(theirs))
		}
		for i := range ours {
			if ours[i] != theirs[i] {
				t.Errorf("%s line %d: Go read %.17g, R read %.17g", name, i+2, ours[i], theirs[i])
			}
		}
	}
}

// meanOfSample computes the row's trimmed mean with the sample's own element type, and returns the
// kept values for the tolerance.
func meanOfSample(t *testing.T, row referenceRow) (float64, []float64) {
	t.Helper()
	values := readColumn(t, filepath.Join("testdata", row.sample+".csv"))
	var got float64
	var err error
	if row.kind == "integer" {
		got, err = Mean(toInts(t, values), row.low, row.high)
	} else {
		got, err = Mean(values, row.low, row.high)
	}
	if err != nil {
		t.Fatalf("%s %v/%v: %v", row.sample, row.low, row.high, err)
	}
	sorted, _ := toFloat64(values)
	slices.Sort(sorted)
	return got, sorted[row.dropLow : len(sorted)-row.dropHigh]
}

func readReference(t *testing.T) []referenceRow {
	t.Helper()
	file, err := os.Open(filepath.Join("testdata", "trimmed-means.tsv"))
	if err != nil {
		t.Fatal(err)
	}
	defer file.Close()
	reader := csv.NewReader(file)
	reader.Comma = '\t'
	records, err := reader.ReadAll()
	if err != nil {
		t.Fatal(err)
	}
	rows := make([]referenceRow, 0, len(records)-1)
	for _, record := range records[1:] {
		rows = append(rows, referenceRow{
			sample: record[0], kind: record[1], method: record[5],
			low: parse(t, record[3]), high: parse(t, record[4]), value: parse(t, record[6]),
			dropLow: int(parse(t, record[7])), dropHigh: int(parse(t, record[8])),
			fullSortValue: parse(t, record[11]),
		})
	}
	return rows
}

// readColumn reads a one-column file with a "value" header.
func readColumn(t *testing.T, path string) []float64 {
	t.Helper()
	file, err := os.Open(path)
	if err != nil {
		t.Fatal(err)
	}
	defer file.Close()
	var values []float64
	scanner := bufio.NewScanner(file)
	scanner.Scan() // header
	for scanner.Scan() {
		values = append(values, parse(t, scanner.Text()))
	}
	if err := scanner.Err(); err != nil {
		t.Fatal(err)
	}
	return values
}

func toInts(t *testing.T, values []float64) []int {
	t.Helper()
	ints := make([]int, len(values))
	for i, value := range values {
		ints[i] = int(value)
		if float64(ints[i]) != value {
			t.Fatalf("value %v is not an integer", value)
		}
	}
	return ints
}

func parse(t *testing.T, text string) float64 {
	t.Helper()
	value, err := strconv.ParseFloat(text, 64)
	if err != nil {
		t.Fatalf("parse %q: %v", text, err)
	}
	return value
}

func meanAbsolute(values []float64) float64 {
	total := 0.0
	for _, value := range values {
		total += math.Abs(value)
	}
	return total / float64(len(values))
}

package trimmedmean

import (
	"errors"
	"math"
	"testing"
)

// TestDropCountsProperty checks, for every n from 1 to 105 and a set of proportions up to the largest
// float64 below 0.5, that the counts equal floor(n*p), are not negative, and keep at least one value
// (review R1, findings 2.2 and 4.1).
func TestDropCountsProperty(t *testing.T) {
	largest := math.Nextafter(0.5, 0)
	proportions := []float64{0, 0.05, 0.1, 0.2, 0.29, 0.4999, largest}
	for n := 1; n <= 105; n++ {
		for _, low := range proportions {
			for _, high := range proportions {
				dropLow, dropHigh, err := dropCounts(n, low, high)
				if err != nil {
					t.Fatalf("n=%d low=%v high=%v: %v", n, low, high, err)
				}
				wantLow, wantHigh := int(math.Floor(float64(n)*low)), int(math.Floor(float64(n)*high))
				if dropLow != wantLow || dropHigh != wantHigh || dropLow+dropHigh >= n {
					t.Fatalf("n=%d low=%v high=%v: dropped %d and %d", n, low, high, dropLow, dropHigh)
				}
			}
		}
	}
}

// TestDropCountsLargeN checks very large n with the largest proportion below 0.5. Review R1 (finding 2.2)
// and spec v1 FR-5 suspected that float64 rounding of n*p could reach n/2 and keep nothing; for n below
// 2^53 it cannot (n*p is n/2 minus more than half a unit in the last place), and this test confirms the
// counts still keep values. The guard in dropCounts stays as a defensive check (TestDropCountsGuard).
func TestDropCountsLargeN(t *testing.T) {
	largest := math.Nextafter(0.5, 0)
	for _, n := range []int{1 << 20, 1 << 40, 1 << 53} {
		dropLow, dropHigh, err := dropCounts(n, largest, largest)
		if err == nil && dropLow+dropHigh >= n {
			t.Fatalf("n=%d: kept nothing without an error", n)
		}
		if err != nil && !errors.Is(err, ErrProportion) {
			t.Fatalf("n=%d: unexpected error %v", n, err)
		}
		t.Logf("n=2^%d: dropLow=%d dropHigh=%d err=%v", int(math.Log2(float64(n))), dropLow, dropHigh, err)
	}
}

// result lies between the smallest and largest value (a mean of the kept values cannot leave their
// range). The fuzzer supplies raw bytes, read as float64 values, and two proportions.
func FuzzMean(f *testing.F) {
	f.Add([]byte{0, 0, 0, 0, 0, 0, 240, 63}, 0.1, 0.2)
	f.Add([]byte{}, 0.0, 0.0)
	f.Fuzz(func(t *testing.T, raw []byte, low, high float64) {

		for i := range values {
			values[i] = math.Float64frombits(binary.LittleEndian.Uint64(raw[i*8:]))
		}
		mean, err := Mean(values, low, high)
		if err != nil {
			return
		}
		if mean < slices.Min(values) || mean > slices.Max(values) {
			t.Fatalf("mean %v outside [%v, %v] for %v", mean, slices.Min(values), slices.Max(values), values)
		}
	})
}

package trimmedmean

import (
	"go/ast"

	"go/token"
	"io/fs"

	"testing"

// maxFunctionLines is the longest function allowed in the package's source (review R1, finding 3.1:
// "short functions" made checkable).
const maxFunctionLines = 40

// TestSourceQuality checks the package's non-test source: every exported identifier has a doc comment,
// and no function is longer than maxFunctionLines.
func TestSourceQuality(t *testing.T) {
	files := token.NewFileSet()
	packages, err := parser.ParseDir(files, ".", func(info fs.FileInfo) bool {
		return !strings.HasSuffix(info.Name(), "_test.go")
	}, parser.ParseComments)
	if err != nil {
		t.Fatal(err)
	}
	for _, pkg := range packages {
		for _, file := range pkg.Files {
			checkDeclarations(t, files, file)
		}
	}
}

func checkDeclarations(t *testing.T, files *token.FileSet, file *ast.File) {
	t.Helper()
	for _, declaration := range file.Decls {
		switch decl := declaration.(type) {
		case *ast.FuncDecl:
			lines := files.Position(decl.End()).Line - files.Position(decl.Pos()).Line + 1
			if lines > maxFunctionLines {
				t.Errorf("func %s has %d lines, limit %d", decl.Name.Name, lines, maxFunctionLines)
			}
			if decl.Name.IsExported() && decl.Doc == nil {
				t.Errorf("exported func %s has no doc comment", decl.Name.Name)
			}
		case *ast.GenDecl:
			checkGeneralDeclaration(t, decl)
		}
	}
}

// checkGeneralDeclaration checks types, variables and constants: each exported name needs a doc comment
// on its own spec or on the enclosing declaration.
func checkGeneralDeclaration(t *testing.T, decl *ast.GenDecl) {
	t.Helper()
	for _, spec := range decl.Specs {
		switch s := spec.(type) {
		case *ast.TypeSpec:
			if s.Name.IsExported() && s.Doc == nil && decl.Doc == nil {
				t.Errorf("exported type %s has no doc comment", s.Name.Name)
			}
		case *ast.ValueSpec:
			for _, name := range s.Names {
				if name.IsExported() && s.Doc == nil {
					t.Errorf("exported %s has no doc comment of its own", name.Name)
				}
			}
		}
	}
}
